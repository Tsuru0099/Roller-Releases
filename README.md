# Roller

为高速图像分类设计。

Windows x64。支持键盘、Xbox 和 PlayStation 手柄。

## 下载

[Windows 安装版](https://roller.tsuru.studio)

运行组件与教程内置。安装后直接使用。

支持文件夹右键启动。更新由用户确认下载和安装。

当前安装包未签名。

## 数据

照片处理在本机完成。PACK 按分类整理文件。

设置、分类记录和缓存保存在 Roller 应用数据目录。卸载可选择清除应用数据，照片不被删除。

默认启用使用统计，不包含照片、文件名或目录路径。详见 [隐私说明](PRIVACY.md)。
